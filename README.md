차트 1. 성별에 따른 육아휴직 확산 현황 (2021 vs 2024)
차트 종류: 그룹 막대 차트
사용 테이블: 성별현황
인사이트: 남성 수급자가 2021년 29,041명에서 2024년 41,830명으로 44% 증가
전체 중 남성 비율이 **26.3% → 31.5%**로 5.2%p 상승
'부모함께 육아휴직제' 도입(2024) 등 제도 개선이 남성 참여 확대에 기여한 것으로 보임

차트 2. 육아휴직 수급자수 vs 출생아수 추이 (2020~2024)
차트 종류: 이중 라인 차트
사용 테이블: 모성보호 + 출생등록 (연도+월 JOIN)
인사이트:
출생아수는 2020→2023년 꾸준히 감소했으나 2024년 소폭 반등
육아휴직 수급자수는 같은 기간 지속 증가 (97만 → 125만)
출생아수 감소에도 육아휴직 사용은 늘어 제도 정착이 진행 중임을 시사

차트 3. 지역별 육아휴직 사용 현황 비교 (2021 vs 2024)
