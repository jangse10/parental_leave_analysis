1. 성별현황 테이블
원본 파일: 공공데이터_청구_성별_육아휴직급여_수급자수 (2021년, 2024년)

처리: 당월 수급자수 = 해당월 누계 - 전월 누계 공식으로 월별 실수치 변환
결과: 2021년·2024년 데이터를 통합하여 연도·성별·월별 수급자수 테이블 구축 (48행)

2. 지역별현황 테이블
원본 파일: 공공데이터_청구_지역별_육아휴직급여_수급자수 (2021년, 2024년)
문제: 성별현황과 동일하게 2021년 파일이 누계 형식으로 제공됨
처리: 동일하게 누계 → 당월 수치 변환 적용
결과: 2021년·2024년 17개 시도별·월별 수급자수 테이블 구축 (420행)

3. 모성보호 테이블

문제 1: Excel 병합셀 구조로 인해 연월 정보가 6개 컬럼마다 한 번만 기재되어 나머지 셀은 빈값으로 읽힘
처리 1: AI를 활용해 Forward fill 방식으로 빈 연월 칸을 앞의 값으로 채워 연월 정보 복원
문제 2: 연월이 컬럼명으로 가로로 펼쳐진 Wide format으로 분석에 부적합
처리 2: Pivot 변환으로 연도·월을 행으로, 급여 종류를 열로 재구성
결과: 전국 합계 기준 월별 모성보호 급여 수급자수 테이블 구축 (60행)

4. 출생등록 테이블
원본 파일: 202001_202412_주민등록인구기타현황_출생등록_월간.csv
문제: 연월이 컬럼명으로 가로로 펼쳐진 Wide format이며, 전국·시도별 행이 혼재
처리 1: '전국' 행만 추출
처리 2: 컬럼명에서 연도·월을 추출하여 Long format으로 변환
